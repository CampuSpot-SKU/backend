# RAG 근거 인용 평가용 정답 세트 (S-7)

`rag-regulation-qa.csv` — 행정 문의 RAG(`/rag/answer`)가 근거 조항을 맞게 인용하는지 보는 정답 세트.

| 열 | 뜻 |
|---|---|
| 질문 | 학생이 물을 법한 말투의 질문 |
| 근거조항 | **학칙(2025.10.1판) 조 번호** — 원문에서 직접 확인한 정답. `;`로 여러 개. `없음`이면 근거가 없어야 하는 질문 |
| 허용조항 | 같은 내용을 다루는 **규정집(2024.9.1 기준) 조항**도 정답으로 인정 — `규정명 제N조`, `;`로 여러 개. 규정집에 대응 조항이 없으면 빈칸 |

## 채점 기준
- 일반 질문: `sources`에 `근거조항` 또는 `허용조항` 중 하나라도 있으면 인용 성공.
- `없음` 질문: `sources`가 비어 있고 "학교 자료에서 근거를 찾지 못했어요" 안내가 나오면 성공(지어낸 답·엉뚱한 조항 인용은 실패).
- 정답은 학칙·규정집 원문에서 사람이 대조해 만들었다(RAG 결과를 보고 만들지 않음). 질문과 정답 작성자가 같아 낙관적일 수 있으므로 보고서엔 한계를 함께 적는다.
